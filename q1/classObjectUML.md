## Class Description

The Student class serves as a blueprint for representing a student of 9 Magnesium for S.Y. 2026-2027. It defines the common attributes and behaviors that a 9 Magnesium student may have.

## Properties
| Property | Data Type | Description |
|---|---|---|
| Name | string | Student's full name |
| Dorm | int | Student's dorm number, with choices from 1 to 3 |
| ALP Club | string | Name of the ALP club that the student belongs to |
| Roman Catholic | boolean | Indicates whether the student is catholic or not |

## Methods
| Method | Description |
|---|---|
| study(subject, time) | A student is able to study a specific subject for a certain amount of time. |
| socialize(person) | A student is able to spend time and interact with another person. |
| sleep() | A student is able to sleep after their daily activities |
